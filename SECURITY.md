# Security and private reports

Experimental pre-OS GPU code; one successful attempt with bounded validation.

Use GitHub private vulnerability reporting when available for sensitive findings. Otherwise file a non-sensitive issue requesting a private channel. Do not publish secrets or dumps. No response-time guarantee.

Unproved cleanup/restoration requires physical shutdown and PSU power removal before proceeding. Preserve original reports privately. No ROM/PROM, firmware, UUID, serial, hostname or personal paths in public reports.
